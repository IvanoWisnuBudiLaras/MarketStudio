# Goals dan outcome
Status: draft turunan BRD. North Star: membantu UMKM memahami kondisi usaha dan mengambil keputusan yang lebih baik melalui workspace terintegrasi.

| ID | Outcome pengguna | Cara validasi kandidat |
|---|---|---|
| G-01 | Mencatat operasi tanpa beban enterprise | Observasi pengguna menyelesaikan purchase/sale atau service sale |
| G-02 | Memahami laba dan kas | Pengguna dapat menjelaskan mengapa pembelian stok tidak sama dengan HPP |
| G-03 | Mengetahui stok dan waste | Rekonsiliasi ledger dan drill-down batch |
| G-04 | Mendapat review yang bisa dipercaya | Semua angka AI cocok dengan metric snapshot dan periode |
| G-05 | Menguji keputusan sebelum bertindak | Skenario harga/volume tidak mengubah actual ledger |
| G-06 | Membuat materi promosi | Draft dapat diedit, direview, diekspor |
| G-07 | Menjangkau beberapa kanal | Status per kanal jujur, kegagalan parsial dapat dipulihkan |
| G-08 | Menggunakan fitur sesuai jenis usaha | Jasa tidak diwajibkan memiliki recipe; hybrid dapat memakai keduanya |

Reference case Bakso: gunakan GOALS asli untuk contoh dashboard, bukan klaim data produksi. Tampilkan actual, estimate dan simulation secara terpisah. Goal tidak menentukan framework, database atau model AI. Jika sebuah fitur tidak mendukung goal, Atlas harus menjelaskan alasan sebelum memasukkannya ke backlog. Target numerik keberhasilan belum disepakati; ukur baseline terlebih dahulu.
