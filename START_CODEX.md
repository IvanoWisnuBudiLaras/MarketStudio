# Bootstrap Atlas / Forge / Nexus

Instruksi pertama: baca README, AGENTS, PROJECT_CONTEXT, docs/DECISIONS, ROADMAP dan docs/engineering/AI_TEAMMATE.md. Periksa repo lokal, versi Orca/harness, git status, model yang tersedia, skill discovery dan MCP capability secara read-only. Jangan menginstal atau menghubungkan apa pun tanpa izin.

Output bootstrap: (1) ringkasan visi dan enam studio; (2) keputusan approved vs proposed; (3) daftar konflik dan missing evidence; (4) inventory lingkungan aktual tanpa secret; (5) usulan satu ticket kecil dengan acceptance criteria; (6) rekomendasi cara menjalankan Atlas, Forge dan Nexus secara bergantian. Jangan langsung coding aplikasi. Jangan membuat 15 agent. Jangan menebak model ID atau format konfigurasi Orca. Jika tidak ada Orca, gunakan manual handoff melalui Git/Markdown sebagai fallback.

Prompt yang bisa dipakai: “Baca START_CODEX.md. Lakukan bootstrap read-only, lalu laporkan temuan dan ajukan satu ticket pertama. Gunakan Bahasa Indonesia dan pertahankan istilah teknis Inggris.”
